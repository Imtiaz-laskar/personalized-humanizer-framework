# 8. Failure Taxonomy

The framework catalogs 18 specific failure modes (**F01 through F18**), defining the exact risk condition and the required corrective protocol:

| Code | Name | Risk Description | Corrective Protocol |
|---|---|---|---|
| **F01** | **Generic AI** | Specificity, concrete grounding, and context are missing. | Add concrete anchors, specify details, and recover underlying reasoning. |
| **F02** | **Hyper-personalization** | Characteristic user traits are inserted everywhere indiscriminately. | Apply contextual gating; limit trait application frequency to appropriate moments. |
| **F03** | **Over-polishing** | Natural hierarchy and expressive asymmetry disappear into clinical perfection. | Restore functional variation, asymmetrical sentence lengths, and conceptual priority. |
| **F04** | **Over-compression** | Foundational explanation is displaced by premature punchlines. | Explain mechanisms and rationale before compressing into conclusions. |
| **F05** | **Under-explanation** | Important causal mechanisms or background contexts are omitted. | Add essential explanatory steps required for clarity. |
| **F06** | **Evidence inflation** | Claims are stated with stronger confidence than source evidence warrants. | Downgrade claim strength to match evidentiary backing. |
| **F07** | **Rhetorical inflation** | Too many rhetorical questions, stark contrasts, punchlines, and buzzwords. | Lower rhetorical temperature; eliminate unearned flourishes. |
| **F08** | **Genre mismatch** | Personal voice is applied without regard to the conventions of the target genre. | Reclassify target context and calibrate genre constraints. |
| **F09** | **Register mismatch** | Language is either too formal or too colloquial for the intended audience. | Recalibrate lexical register to match the target readership. |
| **F10** | **Technical degradation** | Precision is lost through superficial conversationalization. | Lock technical terminology, operational definitions, and precise relationships. |
| **F11** | **Artificial imperfection** | Errors, typos, or sloppy grammar are introduced to mimic human flaws. | Restore technical competence and standard grammatical correctness. |
| **F12** | **Meaning drift** | The transformation alters the fundamental argument, premise, or factual content. | Run semantic comparison against source; revert altered claims. |
| **F13** | **False confidence** | Appropriate uncertainty or probabilistic statements become absolute claims. | Lock epistemic strength; restore hedging terms. |
| **F14** | **Qualification dumping** | Caveats are piled together into clumsy, unreadable disclaimers. | Integrate qualifications organically where they address legitimate inferences. |
| **F15** | **False balance** | Evidence-weighted conclusions are rendered artificially neutral or ambiguous. | Preserve the evidence-weighted asymmetry present in the source analysis. |
| **F16** | **Over-contextualisation** | Irrelevant background history or tangential commentary is inserted. | Remove extraneous context that does not serve the core argument. |
| **F17** | **Implication inflation** | A narrow, specific finding is blown up into a sweeping global conclusion. | Narrow the scope of the conclusion back to the supported finding. |
| **F18** | **Voice flattening** | Distinctive, supported decision-making patterns disappear into generic blandness. | Restore validated, authentic personal characteristics from the profile. |
